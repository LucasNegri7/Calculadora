🧮 Calculadora

Calculadora web desenvolvida com HTML, CSS e JavaScript puros, sem frameworks ou dependências externas. Além das operações básicas, ela mantém um histórico dos cálculos realizados.

✨ Funcionalidades
Operações básicas: soma (+), subtração (−), multiplicação (×) e divisão (÷)
Porcentagem (%)
Separador decimal (,)
Botão C para limpar tudo
Botão ⌫ para apagar o último dígito
Visor com a expressão atual e o resultado
Painel de histórico com botão para limpá-lo
🛠️ Tecnologias
Tecnologia	Uso
HTML5	Estrutura da página e dos botões
CSS3	Estilização e layout
JavaScript	Lógica da calculadora e do histórico
📁 Estrutura do projeto
Calculadora/
├── index.html   # Estrutura da interface
├── style.css    # Estilos
├── script.js    # Lógica da calculadora
└── README.md
🚀 Como executar

Não é necessário instalar nada.

Clone o repositório:
bash
   git clone https://github.com/LucasNegri7/Calculadora.git
Entre na pasta do projeto:
bash
   cd Calculadora
Abra o arquivo index.html no seu navegador (dois cliques no arquivo ou arrastando-o para uma janela do navegador).
🖱️ Como usar
Clique nos números e operadores para montar a conta.
Pressione = para ver o resultado.
Use C para zerar a calculadora ou ⌫ para corrigir o último dígito.
Consulte os cálculos anteriores no painel Histórico e use Limpar histórico para esvaziá-lo.
