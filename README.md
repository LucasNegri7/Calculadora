# 🧮 Calculadora
   🔗 **Veja online:** lucasnegri7.github.io/Calculadora/
   
Calculadora web desenvolvida com **HTML**, **CSS** e **JavaScript** puros, sem frameworks ou dependências externas. Além das operações básicas, ela mantém um **histórico** dos cálculos realizados.

## ✨ Funcionalidades

- Operações básicas: soma (`+`), subtração (`−`), multiplicação (`×`) e divisão (`÷`)
- Porcentagem (`%`)
- Separador decimal (`,`)
- Botão `C` para limpar tudo
- Botão `⌫` para apagar o último dígito
- Visor com a expressão atual e o resultado
- Painel de **histórico** com botão para limpá-lo

## 🛠️ Tecnologias

| Tecnologia | Uso |
|------------|-----|
| HTML5 | Estrutura da página e dos botões |
| CSS3 | Estilização e layout |
| JavaScript | Lógica da calculadora e do histórico |

## 🚀 Como executar

Não é necessário instalar nada.

1. Clone o repositório:
   ```bash
   git clone https://github.com/LucasNegri7/Calculadora.git
   ```
2. Entre na pasta do projeto:
   ```bash
   cd Calculadora
   ```
3. Abra o arquivo `index.html` no seu navegador (dois cliques no arquivo ou arrastando-o para uma janela do navegador).

## 🖱️ Como usar

1. Clique nos números e operadores para montar a conta.
2. Pressione `=` para ver o resultado.
3. Use `C` para zerar a calculadora ou `⌫` para corrigir o último dígito.
4. Consulte os cálculos anteriores no painel **Histórico** e use **Limpar histórico** para esvaziá-lo.
